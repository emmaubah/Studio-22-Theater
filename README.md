
# Studio 22 Movie Theater

## Project Description
Studio 22 is a simple movie theater website created

The website displays movies currently showing, theater information, and contact details. The main purpose of this project is to practice reusing PHP code with separate header and footer files.

## Technologies Used
- PHP
- HTML
- CSS

## Project Files
- `header.php` - Website header and navigation.
- `home.php` - Main page with movie information.
- `footer.php` - Copyright and contact information.
- `style.css` - Website design and styling.
- `images/` - Movie poster images, if included.

## How to Run
1. Install and open XAMPP.
2. Place the project folder inside `xampp/htdocs`.
3. Start Apache.
4. Open `http://localhost/homework3/home.php` in your browser.

## What I Learned
This project helped me understand how to use PHP `include()` statements to reuse headers and footers without repeating the same code on every page.
